# FFD Display

`ffd-display.ttf` is the font for the site name, page titles and headings
(`app/layout.tsx`). It is **Fugaz One** by LatinoType, unchanged except for the
lowercase **f**: Fugaz One's f has a looped tail below the line, so it was
redrawn as a straight f, built from the font's own r (same stem, slant and
curve) plus a crossbar at x-height. Every other letter, the spacing and the
kerning are the original.

Fugaz One is licensed under the SIL Open Font License 1.1 (`OFL.txt`), which
allows modified versions. Its name is reserved for the original, so this one is
called "FFD Display". Keep `OFL.txt` next to the font file.
